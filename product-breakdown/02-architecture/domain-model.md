# Domain Model

## Core Concepts

### PackageSpec
The top-level parsed representation of a package specification. Contains metadata, FMU references, internal connections, wrapper variable declarations, solver configuration, and wrapper configuration. Created by `parse_spec()` from a complete SSP package (`.ssp`) archive.

- Source: `src/cs_fmu_packager/models.py` (`PackageSpec` dataclass)

### ME FMU (Model Exchange FMU)
An input FMU that provides equations and state derivatives via the FMI 2.0 Model Exchange interface. Each internal FMU is identified by a unique name in the package specification and referenced by its `source` URI inside the SSP archive; the packager extracts it into the build workspace during parsing.

- Source: `src/cs_fmu_packager/models.py` (`FmuRef` dataclass)

### Co-Simulation FMU
The output FMU generated by the packager. It exposes an FMI 2.0 Co-Simulation interface while internally instantiating and advancing Model Exchange FMUs.

- Source: Generated by `src/cs_fmu_packager/packager.py` (`assemble_fmu()`)

### Connection
A directed variable-level link between two internal FMUs. Connects a source FMU output to a target FMU input. Sources and targets are expressed as SSP connection endpoints (`startElement`/`startConnector`, `endElement`/`endConnector`), normalized to `<fmu_id>/<variable_name>` references.

- Source: `src/cs_fmu_packager/models.py` (`Connection` dataclass)

### Wrapper Variable
A variable exposed at the packaged Co-Simulation FMU boundary. Can be an input (mapped to an internal FMU target variable), an output (mapped from an internal FMU source variable), or a parameter (mapped to an internal FMU target variable with a start value).

- Source: `src/cs_fmu_packager/models.py` (`WrapperVariable`, `MappedVariable` dataclasses)

### Solver Configuration
Defines the local ODE solver used to advance internal FMU states between communication steps. Includes solver type (v1: fixed_step only), internal step size, communication step size, and algebraic loop handling parameters (max_iterations, tolerance).

- Source: `src/cs_fmu_packager/models.py` (`SolverConfig`, `AlgebraicLoopConfig` dataclasses)

### MappingTable
The resolved mapping produced by the mapper phase. Contains inspected FMU metadata, resolved wrapper variable mappings, resolved connections, detected algebraic loops (SCCs), and execution order. Serves as the input to code generation.

- Source: `src/cs_fmu_packager/models.py` (`MappingTable` dataclass)

### BuildReport
A machine-readable summary of a packaging run. Contains tool version, FMU count, variable count, connection count, algebraic loop count, solver policy, GUIDs, and warnings.

- Source: `src/cs_fmu_packager/models.py` (`BuildReport` dataclass)

## Relationships

```
PackageSpec (input)
  ├── FmuRef (N) — input FMU files
  ├── Connection (N) — internal wiring
  ├── WrapperVariable (N) — boundary variables
  ├── SolverConfig (1) — solver policy
  └── WrapperConfig (1) — wrapper policy
  
MappingTable (resolved)
  ├── Fmi2ModelDescriptionDocument (N) — inspected FMU info
  ├── MappedVariable (N) — resolved wrapper variables
  ├── ResolvedConnection (N) — resolved connections
  ├── AlgebraicLoop (N) — detected SCCs
  └── execution_order — computed order

BuildReport (output metadata)
  └── Summary of packaging run
```
