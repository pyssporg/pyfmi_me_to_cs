# UC-005: Validate Wrapper Semantics

## Actor

Tool developer.

## Preconditions

- Small reference Model Exchange FMUs with known behavior exist.
- The developer needs to verify that generated wrappers handle initialization, stepping, events, and variable propagation correctly.

## Main Flow

1. The developer packages small reference Model Exchange FMUs with the packager.
2. The developer checks wrapper outputs against expected traces.
3. Limitations in solver and event-handling are documented early.

## Success Outcome

Automated tests catch regressions in stepping, variable mapping, and metadata generation. Wrapper behavior can be tested independently from complex physical models.
