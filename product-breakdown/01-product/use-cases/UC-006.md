# UC-006: Generate Co-Simulation FMUs From A Declarative Spec

## Actor

Upstream generator (automated tool).

## Preconditions

- An upstream tool produces a package specification from a graph, SysML model, SSP model, or other architecture description.

## Main Flow

1. The upstream generator produces a TOML package specification file describing FMUs, connections, variables, and solver policy.
2. The packager consumes the specification and creates a Co-Simulation FMU without manual wrapper programming.
3. The packager emits a build report documenting the results.
4. The specification is stored in version control alongside the generated FMU.

## Success Outcome

The same specification produces byte- or metadata-stable artifacts across runs, except for explicitly recorded build timestamps or tool versions. Packaging becomes reproducible and automatable. Large experiment matrices can be generated consistently.
