# IMP-006: Add CI configuration to build and test the package

## Status

Evolution

## Theme

Continuous integration

## Evidence

- No `.github/workflows/` directory exists in the repository
- `README.md` has no CI status badge
- `vcpkg.json` exists at repository root indicating vcpkg-managed dependencies (SUNDIALS)

## Current Pain Or Risk

There is no automated CI pipeline to build the package, run tests, or catch regressions. Contributors cannot verify that their changes pass tests without a local vcpkg + SUNDIALS setup. There is no automated check that the vcpkg-managed SUNDIALS dependency resolves correctly. Pull requests cannot be validated automatically.

## Proposed Improvement

Add a GitHub Actions workflow (`.github/workflows/test.yml`) that:
1. Sets up Python (matrix: 3.9, 3.10, 3.11, 3.12)
2. Bootstraps vcpkg
3. Installs SUNDIALS via vcpkg
4. Installs the package (`pip install .`)
5. Runs CMake build with vcpkg toolchain
6. Executes test suite (`pytest`)

## Expected Benefit

Every push and pull request is automatically built and tested. Contributors get fast feedback. The project gains a CI status badge for the README. Regression detection becomes automated.

## Risk And Blast Radius

Medium. New files only (`.github/workflows/test.yml`). Risk is limited to CI runtime (vcpkg bootstrap can be slow, SUNDIALS build times may hit runner limits). No code changes. The workflow may initially fail if vcpkg caching is not configured or if SUNDIALS takes too long to compile from source.

## Task Contract Seed

Create `.github/workflows/test.yml` with: on-push and on-pull_request triggers for the main branch. Job: `test` with matrix `python-version: ['3.9', '3.10', '3.11', '3.12']`. Steps: checkout, setup-python, vcpkg checkout (`actions/cache` for vcpkg artifacts), `vcpkg install`, `pip install .`, `pytest`. Use `vcpkg`'s binary caching to speed up SUNDIALS resolution.

- Adding code coverage, linting, or static analysis
- Adding deployment or release automation
- Adding non-vcpkg test variants (see IMP-009)

## Traceability

## Notes

vcpkg bootstrap adds ~30-60s per run. SUNDIALS compilation from source adds ~2-5 minutes. Consider using `vcpkg` binary caching or pre-built SUNDIALS binaries to reduce runtime. See also IMP-011 (test without full vcpkg toolchain).
