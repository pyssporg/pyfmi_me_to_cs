# IMP-016: Remove unused imports across source files

Use this template for one backlog-ready improvement candidate.

Candidate

## Status

Proposed

## Layer

Evolution

## Theme

Code cleanup, lint warning resolution

## Evidence

- `src/cs_fmu_packager/cli.py` — imports `json` but never uses it
- `src/cs_fmu_packager/builder.py` — imports `shutil` but never uses it
- `src/cs_fmu_packager/packager.py` — imports `shutil` but never uses it
- `src/cs_fmu_packager/models.py` — has both `import dataclasses` and `from dataclasses import dataclass, field`; the former is redundant

## Current Pain Or Risk

- Each unused import is a lint warning that clutters analysis output and may mask real issues
- Redundant `import dataclasses` with `from dataclasses import dataclass, field` is a minor maintenance smell
- Unused imports create false expectations about module capabilities for new contributors reading the imports

## Proposed Improvement

- Remove `import json` from `cli.py`
- Remove `import shutil` from `builder.py`
- Remove `import shutil` from `packager.py`
- In `models.py`, remove the standalone `import dataclasses` line (keep `from dataclasses import dataclass, field`)

## Expected Benefit

- Cleaner imports, fewer lint warnings
- Reduced cognitive load when scanning module dependencies
- Trivial reduction in module load time (negligible in practice)

## Risk And Blast Radius

Zero risk. Pure removal of unused symbols. No behavioral changes. Test suite should continue to pass without modification.
