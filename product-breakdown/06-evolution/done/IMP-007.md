# IMP-007: Improve vcpkg discovery error message with actionable installation guidance

Use this template for one backlog-ready improvement candidate.

An improvement candidate is not implementation approval. It needs a scoped task contract before code or documentation changes begin.

## Lifecycle Stage

Candidate

## Status

Proposed

## Layer

Evolution

## Theme

User experience and onboarding

## Evidence

- `src/cs_fmu_packager/builder.py` lines 61–63: Error message `"vcpkg root not found. Set VCPKG_ROOT environment variable or pass --vcpkg-root"`

## Current Pain Or Risk

When `_find_vcpkg_root()` fails after probing five heuristic locations, the error message tells the user *what* to do (set env var or CLI flag) but not *how* — there is no link to vcpkg installation instructions, no example command for installing vcpkg, and no hint about the `vcpkg install` step required after installing vcpkg. A new user unfamiliar with vcpkg has no guidance on how to proceed.

## Proposed Improvement

Expand the error message to include:
- Link to vcpkg installation: `https://github.com/microsoft/vcpkg`
- Instructions: "Install vcpkg, set VCPKG_ROOT to your vcpkg directory, then run `vcpkg install` to install SUNDIALS"
- Which heuristic paths were checked so users know what was tried

## Expected Benefit

Users encountering a missing vcpkg installation can resolve the issue without external research. The error message becomes a self-contained troubleshooting guide.

## Risk And Blast Radius

Low. String change only in `builder.py`. No behavioral changes, no logic modifications, no test impacts.
