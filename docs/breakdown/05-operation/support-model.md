# Support Model

## Version

v0.1.0 — Initial development release. Open source under MIT license.

## Support Scope

- **Issue tracking**: GitHub Issues (project maintainer responds on a best-effort basis)
- **Documentation**: README.md, docs/ directory, product-breakdown/ directory
- **Community**: Open source contribution model — users are encouraged to report issues and contribute fixes

## What Is Supported

- Bug reports and feature requests through GitHub Issues
- Documentation improvements
- Pull requests following the project's workflow

## What Is Not Supported

- Guaranteed response times
- Dedicated support channels (no email, chat, or phone support)
- Custom solver integration or model-specific debugging
- Windows/macOS platform support (see AD-006 for v1 constraints)
