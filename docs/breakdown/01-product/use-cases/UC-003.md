# UC-003: Compare Solver Placement Alternatives

## Actor

Researcher.

## Preconditions

- A logical system composed of multiple Model Exchange FMUs exists.
- The researcher wants to compare numerical behavior across multiple decompositions of the same logical system.

## Main Flow

1. The same set of Model Exchange FMUs is packaged into different Co-Simulation boundaries:
   - All components exposed separately.
   - Selected strongly connected components grouped.
   - The full system grouped into one FMU.
2. Each packaged FMU includes metadata documenting its solver policy and wrapper boundary.
3. The researcher runs simulations with each decomposition and compares results.

## Success Outcome

Generated FMUs and metadata make each packaging boundary traceable and reproducible. The logical model can stay constant while the solver boundaries change. The resulting experiments isolate decomposition and solver-placement effects.
