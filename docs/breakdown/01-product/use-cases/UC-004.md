# UC-004: Publish A Reusable Subsystem FMU

## Actor

Model supplier.

## Preconditions

- A subsystem is developed internally using Model Exchange FMUs for modular development.
- The supplier wants to distribute the subsystem as a single Co-Simulation FMU while hiding internal structure.

## Main Flow

1. The supplier creates a package specification listing the internal FMUs, their connections, and only the intended boundary variables.
2. The packager generates a Co-Simulation FMU with the specified wrapper interface.
3. The supplier publishes the generated FMU.
4. Downstream users instantiate the packaged FMU without knowing the internal FMU graph.

## Success Outcome

Downstream users can instantiate the packaged FMU without knowing the internal FMU graph. Internal model structure can be hidden or simplified for users. The delivered artifact is easier for downstream tools to consume.
