# UC-001: Package A Strongly Connected Component

## Actor

Experiment generator (automated tool) or simulation architect.

## Preconditions

- A strongly connected component has been identified in a directed dependency graph.
- Model Exchange FMUs for the nodes in the component are available.
- Internal connections and boundary-crossing variables are known.

## Main Flow

1. The actor provides a package specification identifying the internal FMUs, their connections, and the boundary variables.
2. The packager inspects the FMUs, validates the specification, and resolves the mapping.
3. The packager generates a Co-Simulation FMU representing the full SCC.
4. The packager emits a build report documenting the solver policy and internal FMU mapping.

## Success Outcome

The generated Co-Simulation FMU can be connected in an SSP or equivalent system description as one component. The external master no longer needs to schedule the internal feedback loop directly. The SCC becomes a single solver boundary.

## Primary Value

- The SCC becomes a single solver boundary.
- The external master does not need to schedule the internal feedback loop.
- The experiment can compare exposed-loop and grouped-loop architectures.
